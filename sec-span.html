    6.

    What conditions on a matrix \(A\) insures that \(A{\bf x}={\bf b}\) has a solution for all \({\bf b}\) in \({\mathbb R}^n\text{?}\)
    🔗
    Select the best statement. (The best condition should work with any positive integer \(n\text{.}\))
    🔗
    • The equation will have a solution for all \({\bf b}\) in \({\mathbb R}^n\) as long as the columns of \(A\) span \({\mathbb R}^n\text{.}\)
      🔗
      🔗
    • The equation will have a solution for all \({\bf b}\) in \({\mathbb R}^n\) as long as the columns of \(A\) do not include the zero column.
      🔗
      🔗
    • There is no easy test to determine if the equation will have a solution for all \({\bf b}\) in \({\mathbb R}^n\text{.}\)
      🔗
      🔗
    • The equation will have a solution for all \({\bf b}\) in \({\mathbb R}^n\) as long as no column of \(A\) is a scalar multiple of another column.
      🔗
      🔗
    • none of the above
      🔗
      🔗
    🔗
    Solution.
    \({\bf b}\)\({\mathbb R}^n\)\(A\)\({\mathbb R}^n\text{.}\)

    7.

    Assume \(\left\lbrace {\bf u}_1, {\bf u}_2, {\bf u}_3 \right\rbrace\) spans \({\mathbb R}^3\text{.}\)
    🔗
    Select the best statement.
    🔗
    • \(\lbrace\mathbf{u}_1,\mathbf{u}_2,\mathbf{u}_3,\mathbf{u}_4\rbrace\) always spans \(\mathbb{R}^3\text{.}\)
      🔗
      🔗
    • There is no easy way to determine if \(\lbrace\mathbf{u}_1,\mathbf{u}_2,\mathbf{u}_3,\mathbf{u}_4\rbrace\) spans \({\mathbb R}^3\text{.}\)
      🔗
      🔗
    • \(\lbrace\mathbf{u}_1,\mathbf{u}_2,\mathbf{u}_3,\mathbf{u}_4\rbrace\) spans \({\mathbb R}^3\) unless \({\bf u}_4\) is the zero vector.
      🔗
      🔗
    • \(\lbrace\mathbf{u}_1,\mathbf{u}_2,\mathbf{u}_3,\mathbf{u}_4\rbrace\) never spans \({\mathbb R}^3\text{.}\)
      🔗
      🔗
    • \(\lbrace\mathbf{u}_1,\mathbf{u}_2,\mathbf{u}_3,\mathbf{u}_4\rbrace\) spans \({\mathbb R}^3\) unless \({\bf u}_4\) is a scalar multiple of another vector in the set.
      🔗
      🔗
    • none of the above
      🔗
      🔗
    🔗
    Solution.
    \(\left\lbrace\mathbf{u}_1,\mathbf{u}_2,\mathbf{u}_3\right\rbrace\)\(\left\lbrace\mathbf{u}_1,\mathbf{u}_2,\mathbf{u}_3,\mathbf{u}_4\right\rbrace\text{,}\)\(\left\lbrace \mathbf{u}_1,\mathbf{u}_2,\mathbf{u}_3,\mathbf{u}_4\right\rbrace\)\({\mathbb R}^3\text{.}\)
